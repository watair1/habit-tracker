# 브라우저 테스트

`check.mjs`(루트에 있는 것)는 파일을 눈으로 훑어서 잡을 수 있는 실수만 잡아요.
문법 오류, 없는 함수 호출, 하드코딩된 키 같은 것들이요.

여기 있는 건 **진짜 브라우저를 띄워서 앱을 돌려보는** 테스트입니다.
"6일 빠진 습관을 회복 카드가 잡아내나", "최소 버전을 눌렀을 때 연속 기록이
안 끊기나" 같은 건 실제로 실행해봐야 알 수 있거든요.

## 처음 한 번

```powershell
cd test
npm install
npx playwright install chromium
```

앱 자체는 여전히 설치할 게 없어요. 이 `test/` 폴더 안에서만 쓰는 도구입니다.
루트에는 `package.json`이 없고, `index.html`은 그대로 브라우저로 열면 됩니다.

## 돌리기

```powershell
cd test
npm test
```

- `reccheck.mjs` — 회복 시스템 (놓친 습관 판정, 최소 버전, XP 계산, 회복 카드,
  AI 코치의 최소 버전 설정). 서울과 뉴욕 시간대 양쪽에서 돌려요. 날짜 계산이
  시차 때문에 하루씩 밀리는 사고가 예전에 있었어서요.
- `betcheck.mjs` — AI 예측 채점 (연속·성공률·공백 판정, 기한 전 예측은
  건드리지 않기, 삭제된 습관 처리).

`습관 계산(habitPeriodsDetailed, streakCount, successRate)`을 건드렸다면
푸시 전에 꼭 한 번 돌려주세요. 이 셋이 서로 어긋나면 앱이 조용히 거짓말을 합니다.

## 왜 CDN을 가짜로 채우나

테스트 환경에서는 Chart.js, Lucide 같은 걸 인터넷에서 받아올 수 없어서
`page.route()`로 빈 껍데기를 대신 넣어줍니다. 차트 그림 자체가 아니라
계산이 맞는지를 보는 테스트라 문제없어요.
