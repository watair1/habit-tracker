## 1. GPT와 Claude 역할 나누기

| 누구 | 맡는 일 |
| --- | --- |
| **사용자** | 최종 결정. 레퍼런스 사진 주기. 폰으로 써보고 느낌 말하기. Render·Anthropic 콘솔처럼 계정이 필요한 일 |
| **GPT-6** | 아이디어를 넓게 내기, 서로의 안 비판하기, 레퍼런스에서 좋은 점 뽑기, 일러스트 그림 만들기(이미지 생성), 사용자 입장에서 UX 검토 |
| **Claude** | 실제 코드가 어떤지 사실 확인, "지금 데이터로 되나?" 판정, 구현·테스트·배포, 이 `docs/` 문서 관리 |

일하는 규칙
- GPT 아이디어는 Claude가 코드 기준으로 "되는지, 이미 있는지, 데이터가 있는지" 확인한 뒤 사용자에게 올려요.
- 둘이 의견이 다르면 둘 다 장단점을 적어서 사용자가 골라요.
- 사용자가 정한 건 `design-discussion.md`에 "사용자 결정"으로 적어요.
- 이건 **제안**이에요. 사용자가 바꾸고 싶으면 바꿔요.

## 2. Render · Sonnet 적용

- [x] Render에 로그인 잠금 설정 넣기 (사용자, 11/22 완료)
  - `ALLOWED_EMAILS` = AI 쓸 구글 계정들 (쉼표로 구분)
  - `FIREBASE_WEB_API_KEY` = 앱 코드에 이미 공개된 Firebase 웹 키
  - 확인: 로그인 상태로 AI 코치에 "안녕" → 답이 오면 성공
- [ ] Claude Sonnet 5.5로 바꾸기 — **사용자가 2~3주 뒤 키 만들 예정**
  1. [ ] Anthropic 콘솔 가입 → 크레딧 충전(10달러 ≈ 비서 대화 500~1000번 어림) → **월 사용 한도 걸기** → API 키 만들기 (사용자)
  2. [x] 서버가 Claude도 부를 수 있게 고침 (main 반영). `AI_PROVIDER=claude` 면 Claude, 아니면 Gemini. 잠금이 비어 있으면 Claude 안 부름. 거절 시 서버 폴백
  3. [ ] Render에 `AI_PROVIDER=claude`, `ANTHROPIC_API_KEY` 넣기 (사용자)
- [x] AI 비서 생각 깊이 칩 low / medium / high (main 반영. Claude 일 때만 효과)
- [ ] 미해결: "AI가 답을 만드는 데 너무 오래 걸려요" — 잠금 켠 뒤(11/22)에도 그대로. 이제 로그에 `[AI] gemini 12.3초`처럼 걸린 시간이 찍히고, 로그인 확인엔 10초 제한을 걸었음. Sonnet 으로 바꾸면 풀릴 가능성이 큼

## 5. 기능 다듬기 · 추가 · 방향

방향 (합의됨)
- 매일 쓰는 화면(오늘 · 일정)은 쉽고 빠르게, 돌아보는 화면(성장 · AI)은 독창적으로.
- 지어낸 점수는 쓰지 않아요. 숫자는 실제 기록으로 계산할 수 있는 것만.
- 레퍼런스는 따라 하지 않고, 좋은 구성 요소만 가져와 우리 것으로 바꿔요.

기능 후보 (아직 결정 안 함)

| 후보 | 한 줄 설명 | 쉬운 정도 |
| --- | --- | --- |
| 버틴 날 | 최소 버전으로 이어간 날을 따로 기억하고 보여주기 | 쉬움 (데이터 이미 있음) |
| 분야 성장 | 분야별 활동한 날이 쌓이고, "마디"(직접 남기는 성장의 증거)를 기록 | 중간 |
| 나 vs AI 예측 대결 | 내 예측, AI 예측, 실제 결과 비교. 실험(Growth Lab)도 여기로 | 중간 |
| 같이 피는 습관 | "운동한 날 독서 완료율도 높았어요" 같은 습관 사이 관계 | 중간 |
| 그때의 나 | 옛 메모 다시 보기 + 과거 기록 비교 + 미래에 열리는 메모 | 중간 |
| Plan–Reality | 계획한 하루 vs 실제 하루. 체크 시각 저장부터 시작 | 중간 |
| 별자리 | 마디를 사용자가 직접 이어 별자리로 | 어려움 (마디가 먼저) |

| 내 API 키 넣기 (BYOK) | 사용자가 자기 키로 AI 를 씀. 비용은 각자. 공개에 거의 필수. 분석 탭은 이미 이 방식 | 쉬움 |
| 앱 전용 MCP | Claude 앱 같은 AI 에서 말로 습관 체크·질문·분석. Firestore 접근·로그인·보안 필요 | 어려움 |

기능 개선 후보 (Claude 가 코드 기준으로 찾은 것, 사용자 확인 전)
- 사진이 기기끼리 동기화 안 됨
- 할 일이 두 군데(목표 탭 · 하루 탭)라 어디 적을지 헷갈림
- 분석 탭 AI 만 키를 따로 넣어야 함
- AI 기능이 3~4곳에 흩어짐, 통계 탭과 분석 탭 겹침

사용자 방침: **UI/UX 개편을 먼저 끝내고, 그다음 기능.**

나중에 공개한다면: Firebase 로그인과 Firestore 보안 규칙부터 점검하기.
