## 레퍼런스에서 가져갈 것

사용자는 색이 아니라 **레이아웃**을 좋아했어요. 유리 효과, 발광, 그라데이션처럼 “AI가 만든 듯한” 표면 처리는 빼고 배치만 가져와요.

| 이미지 | 가져갈 것 | 안 가져갈 것 |
| --- | --- | --- |
| 1 (금색) | 큰 숫자 하나 → 작은 지표 3칸 → 한 줄 인사이트, 여백, 일관성 | 갈색 톤 |
| 2 (어시스턴트) | 기능별 진입점 4개 + 아래 입력창, 어시스턴트 존재감 | 반투명 방울 장식 |
| 3 (성장 리포트) | 지표 배치, 그래프와 숫자의 균형 | 근거 없는 “성장도 %” |
| 4 (보라) | 성장 영역별 시각화 구성 | 지어낸 능력 점수(집중력 87 등), 보라 네온 |

원칙: 레이더 차트나 점수는 실제 데이터로 계산할 수 있을 때만 써요. 일반 온보딩(시작하기) 화면은 만들지 않고, 첫 습관 등록 안내만 최소한으로 둡니다.

**사용자가 강조한 것 (11/18)**: 마음에 든 건 색이 아니라 구성 요소. 그대로 따라 하지 않고 우리 것으로 바꿔서 가져와요.

## 오늘 탭 개편안

지금 습관 목록은 위에서 7번째에 있어요. 사용자가 말한 “체크하는 데 에너지가 너무 든다”의 직접적인 원인이에요. 개편 목표는 GPT-6가 정리한 다섯 가지예요.

1. 열자마자 지금 할 행동이 보인다.
2. 습관을 완료하는 데 화면 이동이 없다.
3. 끝낸 항목은 확실히 구분된다.
4. 일정과 습관의 관계가 보인다.
5. 부가 정보가 핵심 행동을 방해하지 않는다.

| 지금 | 바꿀 곳 |
| --- | --- |
| 동기부여 문구 + 진행률 링 | 맨 위 한 줄 (날짜 · 3/5 완료) |
| 회복 카드 (따로) | 그대로 따로 둠, 습관 목록 바로 위 (사용자 결정). 놓친 습관은 목록에서도 맨 위 + 주황 테두리 |
| 습관 추가 입력칸 | + 버튼으로 |
| 습관 목록 | 맨 위. 안 한 것 위, 끝난 것 아래로 접기 |
| 기분 | 습관 아래 한 줄 |
| 주간 돌아보기 박스 | 돌아볼 때만 배너로 |
| (새로) | 다음 일정 한 줄 |

시간대별로 접기보다 “안 한 것 위 / 지금 시간대 먼저 / 끝난 것 접기”가 안전해요. 아침 습관을 저녁에 몰아서 체크하는 경우가 많아서예요.

**사용자 결정 (11/18)**: 라임은 너무 흔해서 버려요. 우리만의 색을 찾는 중이에요. 1차 후보는 청자, 송화, 노을, 이끼, 물총새, 저녁 보라. 아래 표의 “라임” 자리는 새 강조색으로 바뀌어요.

| 색 | 쓰는 곳 |
| --- | --- |
| 중립 회색 | 배경, 카드, 글자 |

**뻔한 AI 디자인을 피하는 방법**

- 유리 효과·발광·대각선 그라데이션 빼기. 무광 표면 + 얇은 테두리.
- “쌓임” 모티프를 일관되게: 아이콘, 히트맵, Landscape, 체크 애니메이션.
- 아이콘 동그라미 대신 큰 숫자 + 작은 라벨.
- 모션 품질을 정체성으로 (탭바에서 이미 증명).
- 한 화면에 시그니처 하나: 성장=Landscape, 오늘=체크 애니메이션, AI=어시스턴트 영역.

## 분야 성장

지금 분야 시스템(이름+색, 일정에 붙이기, 주간 목표량·시간표)은 그대로 두고, 그 위에 **활동 기록 + 마디** 두 축을 얹어요. 사용자는 “어느 정도 복잡해도 된다”고 했어요.

- **활동 기록 (자동)**: 단위는 “활동한 날”. 같은 분야를 하루에 여러 번 해도 1일. 완료한 것만 세고, 분야가 없는 예전 기록은 임의로 채우지 않아요. 시간·횟수 같은 자세한 값은 분야 상세 화면에서.
- **마디 (성장의 증거)**: “푸쉬업 처음 30개”처럼 날짜 + 한 줄. 사용자가 직접 남기거나, 주간 목표 달성·업적에서 자동으로. “성장의 증거”라는 말은 직접 남긴 것에만.
- **최근 상태**: 따로 저장하지 않고 계산해서 색의 선명도로만 표현. “잠든” 같은 이름은 붙이지 않아요. 사용자가 “잠깐 쉬는 중”을 직접 표시하는 건 검토 중.
- **연결**: 습관은 만들 때 한 번만 분야 고르기(선택). 할 일은 고르고 싶을 때만. 분야가 없을 때 추천 칩 제공. 계층형 분야는 하지 않아요.
- **자기평가**: 지금은 넣지 않아요(입력 부담).

**코드 확인 결과: “했다”를 믿을 수 있나**

| 기록 | 활동일로 셈 수 있나 |
| --- | --- |
| 습관 | ✅ 날짜별 완료/최소 버전 |
| 일정 | ✅ 돌아보기에서 “완료”한 것만. 안 남기면 모름 |
| 주간 시간표로 만든 일정 | 계획일 뿐. 돌아보기 “완료”만 |
| 하루 할 일 | ✅ 완료 (“부분”은 결정 필요) |
| 목표 탭 할 일 | ❌ 끝낸 날짜가 없음 → 저장 시작 필요 |

필요한 변경은 작아요: 습관·하루 할 일에 분야(선택), 목표 탭 할 일에 완료 날짜, 그리고 마디 저장소 하나.

**추가로 합의한 것**

- **마디**: 자동 마디(주간 목표 달성·업적)와 직접 남긴 마디는 모양으로 구분해요. 직접 남긴 건 수정·삭제 가능. 같은 사건이 두 번 보이지 않게.
- **분야 상세 화면**: Landscape만큼 중요해요. Landscape에서 능선을 누르면 들어가요. 화려함보다 명확함 우선.
  - 상단: 분야 이름, 색, 주요 기록
  - 중단: 주별 활동 기록, 목표 달성 이력
  - 하단: 마디 타임라인, 상세 활동 기록 (실제 시간·횟수)
- **“잠깐 쉬는 중” 직접 표시**: 좋지만 처음엔 안 넣고, 분야 관리 화면을 개선할 때 추가해요.

## Landscape (시간의 풍경)

쌓인 기록을 풍경처럼 그리는 성장 탭의 시그니처예요. 사용자가 고른 잔디밭 아이콘(“쌓인다”)과 이어져요. 사용자는 **테마를 여러 개** 만들고 싶어 하고, 자연 레퍼런스를 많이 갖고 있어요.

**구조**: 데이터 계산은 하나, 그리는 테마는 여러 개. 정직함 규칙을 계산 쪽에서 한 번만 지키면 모든 테마가 자동으로 정직해져요.

**정직함 규칙**

- 능선 높이 = 분야별 주당 활동일(0\~7). 모든 분야에 같은 척도.
- 쉬는 주는 진짜 0(평평한 바닥). 절벽처럼 혼내지도, 높게 꼾지도 않아요.
- 곡선은 실제 값을 넘지 않게(monotone 보간). 없던 활동을 만들지 않아요.
- 마디 표시는 정확한 날짜 자리에.
- 최근 상태는 색 선명도로만. 쉬는 동안에도 쌓인 기록은 그대로.

**화면 배치**: 홈에는 최근 7일을 얇은 띠로(습관 체크 아래), 성장 탭에는 위에 핵심 지표 + 아래 크게. 좌우로 끌어 시간 탐색, 누르면 그 주 기록.

**모든 테마가 지킬 약속 (GPT-6 보완)**

- 렌더러가 값에 임의 배율을 곱하거나 0인 구간에 장식 높이를 더하지 않아요. 장식은 데이터의 뜻을 바꾸지 못해요.
