해빗 트래커 개편안

앱이 복잡하다는 문제를 UI/UX 쪽에서 푸는 계획이에요. 맨 위 탭바 6종은 직접 눌러보면서 보시면 되고, 아래 계획은 아직 앱에 반영하지 않았어요. 확인받은 단계만 하나씩 바꿀게요.

하단 탭바 6종

보내주신 영상을 1초에 20장씩 잘라 보고 움직임을 맞췄어요. 탭을 눌러보세요. '영상 색'은 영상의 종이 질감, '앱 색'은 지금 앱의 검정+라임이에요.

왜 복잡하게 느껴지나

실제 습관 5개를 넣고 폰(412px)과 패드(1280px)로 탭마다 화면을 찍어서 센 숫자예요.

42개기능 수. 기능 찾기 목록 기준
6개하단 탭. 그중 '분석'은 설정과 분석이 섞여 있음
18개팝업창 수
5번째오늘 탭에서 습관 체크가 나오는 순서
3.3장폰에서 통계 탭 길이 (화면 높이 기준)
500px패드에서 쓰는 폭. 1280px 화면의 40%

AI도 두 갈래예요. 비서·일정·총평은 서버 AI를 쓰고, 분석 탭 피드백만 따로 Claude 키를 넣어야 해요. 같은 일을 두 가지 방식으로 하고 있어서 헷갈려요.

디자인 원칙 네 가지

매일 하는 일은 맨 위에

앱을 여는 이유의 대부분은 습관 체크예요. 열자마자 체크할 수 있어야 해요.

가끔 하는 일은 한 겹 안으로

백업, 초기화, 알림, API 키는 한 달에 한 번 볼까 말까예요. 설정 한 곳으로 모아요.

한 화면에 한 가지 질문

탭마다 "지금 뭐 하지?", "잘하고 있나?"처럼 답할 질문 하나만 둬요.

넓은 화면은 넓게

패드에선 두 단으로 펼쳐서, 스크롤 대신 한눈에 보이게 해요.

오늘 탭: 체크가 먼저

위에서부터 나오는 순서예요. 라임색이 앱을 여는 목적(습관 체크)이에요.

회복 카드는 따로 두지 않고, 놓친 습관 줄에 주황 표시로 붙여요. 명언은 하루 한 번 처음 열 때만 잠깐 보여줘요.

탭 6개를 4개로

기능을 빼는 게 아니라 자리를 옮기는 거예요. 주황은 옮겨오는 것, 점선은 설정(⚙)으로 가는 것이에요.

'기록' 탭 안에서는 맨 위에 요약 숫자 4개만 두고, 그래프는 '이번 주 / 이번 달 / 습관별' 세 갈래로 나눠서 한 번에 하나만 보여줘요. 지금처럼 3장 넘게 스크롤하지 않게요.

패드 화면: 두 단으로

화면 폭이 900px을 넘으면 오늘 탭을 두 단으로 펼쳐요. 폰에서는 지금처럼 한 줄이에요.

진행 순서

탭바 애니메이션 6종 · 레벨 해금

레벨이 오를 때마다 하나씩 열리고, 열린 것 중에서 설정에서 골라요. 레벨업 때 "새 탭바가 열렸어요"라고 알려줘요.

모양 확정 후 진행

오늘 탭 정리

습관 체크를 맨 위로, 회복 카드는 습관 줄에 합치기, 메모 접기.

확인 후 진행

탭 4개 + 설정(⚙)

통계·성장·분석을 '기록'으로 합치고, 설정을 헤더로.

확인 후 진행

AI 하나로

서버를 Claude로 바꾸는 작업(Render) 뒤에, 분석 탭의 별도 키 입력을 없애요.

Render 작업 뒤

패드 두 단

넓은 화면에서 오늘·하루 탭을 두 단으로.

확인 후 진행

색·간격 다듬기

카드 테두리·글자 크기·여백을 통일해서 덜 빽빽하게.

확인 후 진행

단계마다 기능 브랜치에만 올리고, 보여드린 뒤 괜찮다고 하시면 실제 사이트(main)에 반영해요.

정해주실 것

  1. 탭바 6종 모양과 레벨 순서, 이대로 괜찮은지 (바뀌는 방식은 레벨 해금으로 정함)
  2. 탭 6개 → 4개 구조, 이대로 괜찮은지
  3. 오늘 탭 순서(체크 먼저), 이대로 괜찮은지
  4. 색은 앱 색(검정+라임)을 유지할지, 영상 색처럼 바꿔볼지
