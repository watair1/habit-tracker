나만의 기능 B

    
B 방법은 미리 만든 부품을 고르는 게 아니라 AI가 그 기능의 코드를 직접 짜. 그래서 부품에 없는 것도 만들 수 있어. 아래 예시를 누르거나 폰 입력창에 아무거나 써 봐. AI가 코드를 쓰는 모습이 그대로 보이고, 미리보기를 확인한 다음 적용해.

    

      
      
      
      
    

    
AI 연결 확인 중…


    
흐름

    
    
      
  1. 말하기 → AI가 코드를 짜는 게 실시간으로 보여
    2. 
      
  2. 미리보기: 점선 카드 안에서 실제로 돌아가
    3. 
      
  3. 고쳐줘: "버튼 작게", "주간도 보여줘"처럼 말로 수정
    4. 
      
  4. 이대로 적용 → 커서가 붙여 줘. 새로고침해도 남아 있어 (이 브라우저에만)
    5. 
    


    
안전장치

    
    
      
  • AI가 짠 코드는 격리된 상자(sandbox iframe) 안에서만 돌아가. 앱 화면 · 저장소 · 로그인에 손을 못 대.
    • 
      
  • 인터넷 접속 금지. 외부 파일도 못 불러와.
    • 
      
  • 내 기록은 읽기 전용 복사본만 받아. 원본 습관 기록은 못 바꿔.
    • 
      
  • 자기 위젯 상태(카운터 숫자 등)만 따로 저장할 수 있어.
    • 
      
  • 미리보기 → 내가 승인해야 붙어. × 로 언제든 지워.
    • 
    

    
기록은 예시 데이터(최근 30일 습관 3개 · 기분)야. AI 호출은 이 페이지를 보는 사람의 Claude 사용량을 써서, 처음 한 번 허락을 물어봐.
